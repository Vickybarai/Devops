# GCP Network Load Balancer (NLB) Setup Guide

This guide walks through creating an external Network Load Balancer with multiple backend Compute Engine instances.

## 1. Set Default Region and Zone
*Change the region and zone if you want to deploy in a different location.*

```bash
gcloud config set compute/region us-central1
```

*Change the zone if needed.*

```bash
gcloud config set compute/zone us-central1-a
```

## 2. Create Multiple Web Server Instances

Create 3 VM instances (www1, www2, www3) with Apache installed.

*Change the instance name `www1` or zone if needed.*

```bash
gcloud compute instances create www1 \
  --zone=us-central1-a \
  --tags=network-lb-tag \
  --machine-type=e2-small \
  --image-family=debian-11 \
  --image-project=debian-cloud \
  --metadata=startup-script='#!/bin/bash
    apt-get update
    apt-get install apache2 -y
    service apache2 restart
    echo "
<h3>Web Server: www1</h3>" | tee /var/www/html/index.html'
```

*Change the instance name `www2` or zone if needed.*

```bash
gcloud compute instances create www2 \
  --zone=us-central1-a \
  --tags=network-lb-tag \
  --machine-type=e2-small \
  --image-family=debian-11 \
  --image-project=debian-cloud \
  --metadata=startup-script='#!/bin/bash
    apt-get update
    apt-get install apache2 -y
    service apache2 restart
    echo "
<h3>Web Server: www2</h3>" | tee /var/www/html/index.html'
```

*Change the instance name `www3` or zone if needed.*

```bash
gcloud compute instances create www3 \
  --zone=us-central1-a  \
  --tags=network-lb-tag \
  --machine-type=e2-small \
  --image-family=debian-11 \
  --image-project=debian-cloud \
  --metadata=startup-script='#!/bin/bash
    apt-get update
    apt-get install apache2 -y
    service apache2 restart
    echo "
<h3>Web Server: www3</h3>" | tee /var/www/html/index.html'
```

### Create Firewall Rule
*Change the firewall rule name `www-firewall-network-lb` or tag `network-lb-tag` if needed.*

```bash
gcloud compute firewall-rules create www-firewall-network-lb \
    --target-tags network-lb-tag --allow tcp:80
```

### Verify Instances
*Run this to list instances and find their IPs.*

```bash
gcloud compute instances list
```

*Replace `[IP_ADDRESS]` with the external IP of any instance above to verify it works.*

```bash
curl http://[IP_ADDRESS]
```

## 3. Configure the Load Balancing Service

### Create Static External IP
*Change the IP name `network-lb-ip-1` or region if needed.*

```bash
gcloud compute addresses create network-lb-ip-1 \
  --region us-central1
```

### Create Health Check
*Change the health check name `basic-check` if needed.*

```bash
gcloud compute http-health-checks create basic-check
```

## 4. Create Target Pool and Forwarding Rule

### Create Target Pool
*Change the pool name `www-pool`, region, or health check name if needed.*

```bash
gcloud compute target-pools create www-pool \
  --region us-central1 --http-health-check basic-check
```

### Add Instances to Pool
*Change the pool name or list of instance names (`www1,www2,www3`) if needed.*

```bash
gcloud compute target-pools add-instances www-pool \
    --instances www1,www2,www3
```

### Create Forwarding Rule
*Change the rule name `www-rule`, region, ports, IP address name, or pool name if needed.*

```bash
gcloud compute forwarding-rules create www-rule \
    --region  us-central1 \
    --ports 80 \
    --address network-lb-ip-1 \
    --target-pool www-pool
```

## 5. Send Traffic to Your Instances

### Get Forwarding Rule IP
*Change the rule name `www-rule` and region if needed.*

```bash
gcloud compute forwarding-rules describe www-rule --region us-central1
```

### Access External IP
*Change the rule name and region to capture the IP into a variable.*

```bash
IPADDRESS=$(gcloud compute forwarding-rules describe www-rule --region us-central1 --format="json" | jq -r .IPAddress)
```

*Display the IP address.*

```bash
echo $IPADDRESS
```

### Test Load Balancing
*Run this loop to see traffic alternate between instances. Press Ctrl+C to stop.*

```bash
while true; do curl -m1 $IPADDRESS; done
```

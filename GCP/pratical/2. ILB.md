# GCP Internal Load Balancer & Prime Calculator Setup

This guide sets up a Python-based "Prime Number Calculator" service behind an Internal Load Balancer, fronted by a public web server to visualize the results.

## 1. Setup Environment & Tools
*Install virtualenv package.*

```bash
sudo apt-get install -y virtualenv
```

*Build the virtual environment named venv.*

```bash
python3 -m venv venv
```

*Activate the virtual environment.*

```bash
source venv/bin/activate
```

*Enable the Gemini for Google Cloud API in Cloud Shell.*

```bash
gcloud services enable cloudaicompanion.googleapis.com
```

**IDE Setup:**
1. Click **Open Editor** on the Cloud Shell toolbar.
2. Click **Cloud Code - No Project** in the status bar.
3. Authorize the plugin and select your Google Cloud Project.

## 2. Create Backend Managed Instance Group

### Create Startup Script
*Create the backend.sh file in your home directory.*

```bash
touch ~/backend.sh
```

*Open `backend.sh` in the editor and paste the following script:*

```bash
sudo chmod -R 777 /usr/local/sbin/
sudo cat << EOF > /usr/local/sbin/serveprimes.py
import http.server

def is_prime(a): return a!=1 and all(a % i for i in range(2,int(a**0.5)+1))

class myHandler(http.server.BaseHTTPRequestHandler):
  def do_GET(s):
    s.send_response(200)
    s.send_header("Content-type", "text/plain")
    s.end_headers()
    s.wfile.write(bytes(str(is_prime(int(s.path[1:]))).encode('utf-8')))

http.server.HTTPServer(("",80),myHandler).serve_forever()
EOF
nohup python3 /usr/local/sbin/serveprimes.py >/dev/null 2>&1 &
```

**Gemini Assist (Optional):**
In the Cloud Shell Editor, click the **Gemini Code Assist** icon > **Explain this**. Use the prompt provided in your lab instructions to understand the script.

### Create Instance Template
*Change the template name `primecalc`, tags, or machine type if needed.*

```bash
gcloud compute instance-templates create primecalc \
--metadata-from-file startup-script=backend.sh \
--no-address --tags backend --machine-type=e2-medium
```

### Open Firewall for Backend
*Change rule name `http` or source ranges `10.142.0.0/20` if your network differs.*

```bash
gcloud compute firewall-rules create http --network default --allow=tcp:80 \
--source-ranges 10.142.0.0/20 --target-tags backend
```

### Create Instance Group
*Change group name `backend`, size, or zone `us-east1-b` if needed.*

```bash
gcloud compute instance-groups managed create backend \
--size 3 \
--template primecalc \
--zone us-east1-b
```

## 3. Set Up Internal Load Balancer

### Create Health Check
*Change health check name `ilb-health` or request path `/2` if needed.*

```bash
gcloud compute health-checks create http ilb-health --request-path /2
```

### Create Backend Service
*Change service name `prime-service`, region `us-east1`, or protocol if needed.*

```bash
gcloud compute backend-services create prime-service \
--load-balancing-scheme internal --region=us-east1 \
--protocol tcp --health-checks ilb-health
```

### Add Instance Group to Backend Service
*Change service name, instance group name `backend`, or zone `us-east1-b` if needed.*

```bash
gcloud compute backend-services add-backend prime-service \
--instance-group backend --instance-group-zone=us-east1-b \
--region=us-east1
```

### Create Forwarding Rule
*Change rule name `prime-lb`, region, or static IP `10.142.0.10` if needed.*

```bash
gcloud compute forwarding-rules create prime-lb \
--load-balancing-scheme internal \
--ports 80 --network default \
--region=us-east1 --address 10.142.0.10 \
--backend-service prime-service
```

## 5. Create Public-Facing Web Server

### Create Frontend Startup Script
*Create the frontend.sh file in your home directory.*

```bash
touch ~/frontend.sh
```

*Open `frontend.sh` in the editor and paste the following script:*

```bash
sudo chmod -R 777 /usr/local/sbin/
sudo cat << EOF > /usr/local/sbin/getprimes.py
import urllib.request
from multiprocessing.dummy import Pool as ThreadPool
import http.server
PREFIX="http://10.142.0.10/" #HTTP Load Balancer
def get_url(number):
    return urllib.request.urlopen(PREFIX+str(number)).read().decode('utf-8')
class myHandler(http.server.BaseHTTPRequestHandler):
  def do_GET(s):
    s.send_response(200)
    s.send_header("Content-type", "text/html")
    s.end_headers()
    i = int(s.path[1:]) if (len(s.path)>1) else 1
    s.wfile.write("<html><body><table>".encode('utf-8'))
    pool = ThreadPool(10)
    results = pool.map(get_url,range(i,i+100))
    for x in range(0,100):
      if not (x % 10): s.wfile.write("<tr>".encode('utf-8'))
      if results[x]=="True":
        s.wfile.write("<td bgcolor='#00ff00'>".encode('utf-8'))
      else:
        s.wfile.write("<td bgcolor='#ff0000'>".encode('utf-8'))
      s.wfile.write(str(x+i).encode('utf-8')+"</td> ".encode('utf-8'))
      if not ((x+1) % 10): s.wfile.write("</tr>".encode('utf-8'))
    s.wfile.write("</table></body></html>".encode('utf-8'))
http.server.HTTPServer(("",80),myHandler).serve_forever()
EOF
nohup python3 /usr/local/sbin/getprimes.py >/dev/null 2>&1 &
```

**Gemini Assist (Optional):**
Use **Gemini Code Assist** > **Explain this** on `frontend.sh` with the prompt provided in your lab instructions.

### Create Frontend Instance
*Change instance name `frontend`, zone `us-east1-b`, or machine type if needed.*

```bash
gcloud compute instances create frontend --zone=us-east1-b \
--metadata-from-file startup-script=frontend.sh \
--tags frontend --machine-type=e2-standard-2
```

### Open Firewall for Frontend
*Change rule name `http2` or source ranges if needed.*

```bash
gcloud compute firewall-rules create http2 --network default --allow=tcp:80 \
--source-ranges 0.0.0.0/0 --target-tags frontend
```

### View Application
1. Navigate to **Compute Engine** > **VM instances**.
2. Find the **External IP** of the `frontend` instance.
3. Paste the IP into your web browser. You should see a matrix of prime numbers highlighted in green.


## **1. Consultant Roles**

These are advisory / solution planning positions.

### 1.1 DevOps Consultant

Advises organizations on CI/CD, automation, deployment workflow, infra modernization, and DevOps toolchain.

### 1.2 Cloud Consultant

Provides cloud migration strategy, cloud cost optimization, architecture suggestions, and service recommendations.

### 1.3 Linux Consultant

Consults on Linux server hardening, system optimization, shell automation, and troubleshooting.

### 1.4 Network Consultant

Works on network planning, VPN, firewall, routing, connectivity, and secure enterprise communication.

### 1.5 Technical Consultant

General technical advisory role across infrastructure, cloud, deployment, and modernization.

---

## **2. Developer Roles**

These are coding + automation + infrastructure scripting positions.

### 2.1 Application Developer

Builds business applications; works with DevOps teams for deployment.

### 2.2 DevOps Developer

Creates automation scripts, CI/CD integrations, deployment logic, IaC modules.

### 2.3 Linux Developer

Works on shell scripting, cron automation, Linux-based backend process development.

---

## **3. Engineer Roles**  ⭐ (Most important market category)

### 3.1 DevOps Engineer

CI/CD, Docker, Kubernetes, Terraform, Jenkins, monitoring, automation, cloud deployment.

### 3.2 Cloud Engineer

Handles AWS/Azure/GCP provisioning, scaling, networking, security, cloud deployment.

### 3.3 Linux Engineer

Linux server management, shell automation, performance tuning, troubleshooting.

### 3.4 System Engineer

Infra + server + deployment + partial support + operational maintenance.

### 3.5 Infrastructure Engineer

Designs and maintains compute, storage, servers, virtualization, cloud infra.

### 3.6 Build Engineer

Focuses on build process, package generation, dependency management, CI integration.

---

## **4. Administrator Roles**

Administration = maintenance + management + operations.

### 4.1 Cloud Administrator

Maintains cloud accounts, IAM, EC2, VPC, security groups, backups, monitoring.

### 4.2 Linux Administrator

Linux server setup, permissions, patching, user management, logs, backup.

### 4.3 System Administrator

Handles servers, networks, users, OS management, uptime.

### 4.4 DevOps Administrator

Manages Jenkins, Git, Docker registries, K8s clusters, deployment permissions.

---

## **5. Support Roles**

### 5.1 DevOps Support Engineer

Monitors pipelines, deployment failures, server incidents, alerts, and ticket handling.

### 5.2 Cloud Support Engineer

Handles AWS issues, infra tickets, access problems, scaling incidents.

### 5.3 Production Support Engineer

Application uptime, deployment issues, release support, logs, hotfix coordination.

---

## **6. Reliability & Platform Roles**

### 6.1 Site Reliability Engineer (SRE)

Works on uptime, incident response, observability, automation, scalability, resilience.

### 6.2 Platform Engineer

Builds reusable infra platforms, internal CI/CD ecosystem, self-service deployment systems.

---

## **7. Release / Deployment Roles**

### 7.1 Release Engineer

Controls deployment scheduling, release execution, version movement.

### 7.2 Release Manager

Plans release windows, approvals, rollback strategy, production release governance.

### 7.3 Build and Release Engineer

Combination of software build generation and production release management.

---

## **8. Architecture Roles** (Higher Level)

### 8.1 Cloud Architect

Designs scalable cloud infra, HA, DR, networking, security architecture.

### 8.2 DevOps Architect

Designs end-to-end DevOps lifecycle, toolchain, deployment strategy, governance.

### 8.3 Infrastructure Architect

Plans server, virtualization, network, hybrid infra, storage architecture.

---

## **9. Database / Backend Infra**

### 9.1 Database Administrator (DBA)

Handles MySQL/PostgreSQL/Oracle database backups, tuning, replication, recovery.

---

## **10. Research / Innovation Roles**

### 10.1 R&D Engineer

Tests new tools, PoCs, automation frameworks, cloud innovation.

### 10.2 DevOps Research Engineer

Researches advanced automation, AI Ops, GitOps, platform modernization.

---
